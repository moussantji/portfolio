# 📱 APK E-commerce - Guide Ultra Simple

## Tu as l'APK sur ton téléphone ?

### Méthode 1 : GitHub Release (RECOMMANDÉ - lien qui marche toujours)
1. Va sur https://github.com/moussantji/gestion-stock (ou ton repo e-commerce)
2. Clique "Releases" → "Draft a new release"
3. Tag: `v1.0.0` - Titre: `E-commerce APK v1`
4. **Glisse ton APK** dans "Attach binaries"
5. Publie → copie le lien du type `https://github.com/.../download/v1.0.0/ecommerce.apk`
6. Donne-moi le lien → je le mets dans le portfolio

### Méthode 2 : Direct dans portfolio
1. Branche téléphone en USB → copie `.apk`
2. Renomme en `ecommerce-v1.apk`
3. Mets dans ce dossier `/apk/`
4. Git push → le bouton devient vert auto

### Méthode 3 : Google Drive
1. Upload APK sur Drive → Partage "Toute personne avec le lien"
2. Donne-moi le lien

## Pour les captures d'écran de l'APK :
1. Ouvre l'app sur téléphone
2. Power + Volume bas = screenshot
3. Fais 3-4 écrans : accueil, produit, panier, profil
4. Envoie-toi en qualité originale (Telegram "Fichier" pas "Galerie")
5. Renomme en `ecommerce-real-1.jpg` etc. → mets dans `/img/projects/`
6. Je les afficherai avec badge vert "Capture réelle"

Taille max GitHub : 100MB par fichier. Si APK >50MB → utilise Release.
