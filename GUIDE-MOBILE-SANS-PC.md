Tu as envoyé 3 captures e-commerce superbes ! Voici comment tout mettre en ligne SANS PC.

## 📲 ÉTAPE 1 : Mettre les captures sur GitHub depuis téléphone

1. Chrome → 3 points → Coche "Version pour ordinateur" ✅
2. Va sur github.com/moussantji/portfolio
3. Va dans dossier `img/projects/`
4. "Add file" → "Upload files" → Choisis tes 3 captures
5. IMPORTANT : Renomme-les AVANT dans ton téléphone :
   - IMG-20260921-WA0158.jpg → `ecommerce-real-1.jpg`
   - IMG-20260921-WA0159.jpg → `ecommerce-real-2.jpg`
   - IMG-20260921-WA0160.jpg → `ecommerce-real-3.jpg`
6. "Commit changes"

## 📦 ÉTAPE 2 : Mettre l'APK en Release (sans PC)

1. Chrome → Mode ordinateur toujours activé
2. Va sur github.com/moussantji/gestion-stock/releases
3. "Draft a new release"
4. Tag: `v1.0.0` - Title: `E-commerce APK v1`
5. Glisse ton APK dans "Attach binaries"
6. Publish
7. Copie le lien du fichier dans Assets (appui long → copier lien)
8. Envoie-moi le lien

## 🔗 Le lien ressemblera à :
`https://github.com/moussantji/gestion-stock/releases/download/v1.0.0/ecommerce-v1.apk`

Je le mettrai dans ton portfolio avec bouton vert direct.
