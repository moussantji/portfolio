# 📱 Portfolio - Guide 100% Téléphone (Sans PC)

## Problème "Unable to validate tag" ?

**Solution rapide :**
- Au lieu de `v1.0.0`, mets `v1.0.1` ou `apk-v1` ou `ecommerce-v1`
- Le tag existe déjà, il faut un nouveau nom
- Pas d'espace

**Solution la plus simple (SANS tag, SANS Release) :**
1. Va sur github.com/moussantji/portfolio (Chrome → 3 points → Version pour ordinateur ✅)
2. Va dans dossier `apk/`
3. Add file → Upload files → choisis ton APK `ecommerce-v1.apk`
4. Commit changes
5. Le bouton devient vert auto !

## Pour les captures :

Même méthode :
github.com/moussantji/portfolio → img/projects/ → Add file → Upload → tes 3 captures renommées ecommerce-real-1/2/3.jpg

## Dossier apk visible ?

Maintenant oui ! Sur main et arena branch.
Si tu ne le vois pas : sur GitHub, en haut tu as un bouton "main" → clique → choisis "arena/01a0c560-portfolio" ou "main", tu verras apk/
